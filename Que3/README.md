# Frugal Testing Assignment Q3

The Part B VS Code implementation is stored in `.github/copilot-instructions.md`.
VS Code and GitHub Copilot can use workspace instruction files automatically
for chat and agent sessions in this folder.

`AI_LOCATOR_ASSISTANT_PROMPT.md` contains a standalone copy suitable for:

- ChatGPT or another AI chat
- Custom Copilot prompt configuration
- Submission documentation

The instructions prioritize ARIA roles, accessible names, accessible
relationships, uniqueness verification, semantic locators, fallback locators,
confidence reporting, and ambiguity reporting.
